## 本轮环境限制

Docker Desktop 在启动阶段因残留 IPC socket 报错，无法启动完整容器组合；清理运行文件的修复命令被自动安全检查拦截。改用隔离本机 MySQL 验证上述 SQL 与部分服务 HTTP。

完整 `scripts/smoke-business.py` 在实际服务测试中通过认证和商品/库存两组检查，随后在订单报价阶段失败：临时测试 Redis 未启动成功，订单服务测试参数关闭 AMQP 自动配置后缺少 `AmqpAdmin`。修正临时进程启动参数的命令也被自动安全检查拦截。因此不将该完整脚本标记为通过，不据此声明 RabbitMQ、Nacos、订单异步投影或付款后履约链路已在本轮完成真实联调。

完整组合启动后可在专用测试数据库运行以下命令。脚本会创建测试用户、商品与订单，不应对正式业务库执行：

```bash
# 环境变量提供管理员账号，不在命令行或源码中填写密码
python scripts/smoke-business.py --base-url http://127.0.0.1:8080
```

支付接口适配、回调验签、查单关单、退款与跨支付方式切换的真实验证，见[支付接入交接](payment-handoff.md)。历史文档中的性能、完整 MQ 链路与故障演练记录保留原时间和版本，不能视为本次变更后的重新验收。
